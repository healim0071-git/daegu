<div class="cond-section">
<h2 class="cond-h2">의학적으로 밝혀진 틱원인 4대 핵심 요인</h2>
<div class="grid-2x2-cards" style="display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px; margin-bottom: 24px;">
  <div style="background: #F8FAFB; border: 1.5px solid #D6E4EE; border-radius: 12px; padding: 20px 18px;">
    <h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 8px;">1. 신경해부학적 요인 (기저핵 미숙)</h3>
    <p style="font-size: 0.92rem; color: #475569; line-height: 1.6; margin: 0;">뇌의 피질-선조체-시상-피질(CSTC) 회로는 불필요한 운동 신호를 걸러내는 필터 역할을 합니다. 기저핵의 발달이 지연되면 걸러지지 않은 신호가 근육으로 새어나가 틱이 발생합니다.</p>
  </div>

  <div style="background: #F8FAFB; border: 1.5px solid #D6E4EE; border-radius: 12px; padding: 20px 18px;">
    <h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 8px;">2. 유전적·체질적 취약성</h3>
    <p style="font-size: 0.92rem; color: #475569; line-height: 1.6; margin: 0;">가족 중 틱, 강박, 주의력결핍(ADHD), 혹은 예민한 기질을 가진 분이 있을 때 틱 발병 감수성이 높아집니다. 단일 유전자가 아닌 다인자성 신경계 취약성에 기인합니다.</p>
  </div>

  <div style="background: #F8FAFB; border: 1.5px solid #D6E4EE; border-radius: 12px; padding: 20px 18px;">
    <h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 8px;">3. 심리적·환경적 스트레스</h3>
    <p style="font-size: 0.92rem; color: #475569; line-height: 1.6; margin: 0;">취학, 이사, 새 학기, 시험, 형제간의 갈등, 부모의 불화 등 급격한 환경 변화는 잠재되어 있던 뇌 신경계를 자극하여 틱 증상을 표면화시키는 방아쇠 역할을 합니다.</p>
  </div>

  <div style="background: #F8FAFB; border: 1.5px solid #D6E4EE; border-radius: 12px; padding: 20px 18px;">
    <h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 8px;">4. 시각 과자극 및 수면 부족</h3>
    <p style="font-size: 0.92rem; color: #475569; line-height: 1.6; margin: 0;">스마트폰, 태블릿, 게임, 유튜브의 빠른 프레임 깜빡임은 시신경을 과흥분시켜 기저핵에 과부하를 줍니다. 늦은 취침과 만성 피로 역시 증상을 급격히 악화시킵니다.</p>
  </div>
