<h2 style="font-size: 1.22rem; font-weight: 800; color: #0C4349; margin-top: 0; margin-bottom: 12px; display: flex; align-items: center; gap: 8px;">
<span>🌿</span> 왜 자율신경계는 피검사나 내시경이 아닌 'HRV 검사'로 측정해야 할까요?
</h2>
<p style="margin: 0 0 10px; color: #334155;">
일반 병원 종합검진(혈액검사, 위내시경, 심전도, 뇌 MRI)은 장기의 세포가 파괴되었거나 궤양이 생겼는지 보는 '구조적 검사'입니다. 반면 자율신경계는 혈관의 수축과 이완, 심장 박동수 조절, 체온 조절을 담당하는 '기능적 조절 시스템'이므로, 심장의 미세한 박동 변이(HRV, Heart Rate Variability)를 분석해야만 교감신경의 과열과 부교감신경의 방전 상태를 정확히 진단할 수 있습니다.
</p>
<div style="background: #EFF6F6; border-radius: 8px; padding: 10px 14px; font-size: 0.94rem; color: #0C4349; font-weight: 700;">
💡 해아림한의원 대구본점은 대구 수성구 달구벌대로 범어역 1·4번 출구 앞 두산위브 더제니스 상가 3층에 위치하며, 16년 임상 경험의 한방신경정신과 박사 김대억 대표원장이 직접 1:1 심층 진료합니다.
</div>
</div>

<!-- 1. 섹션 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. HRV(심박변이도) 검사로 확인하는 핵심 4대 지표
</h2>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin: 18px 0;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">① 교감신경 활성도 (SNS)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
외부 스트레스나 긴장에 반응해 심박수를 올리는 가속페달 지표입니다. 과도하게 높으면 이유 없는 가슴 두근거림, 불안, 상열감, 불면증이 유발됩니다.
</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">② 부교감신경 활성도 (PNS)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
몸을 쉬게 하고 소화와 수면을 돕는 브레이크 지표입니다. 수치가 바닥으로 떨어지면 만성 피로, 소화불량, 장 무력증, 안구건조가 고착화됩니다.
</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">③ 자율신경 균형도 (LF/HF Ratio)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
교감과 부교감의 시소 균형을 나타냅니다. 정상 비율(약 1:1.5)을 벗어나 교감신경 쪽으로 심하게 기울면 자율신경실조증으로 판정합니다.
</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">④ 스트레스 저항도 및 혈관 탄성도</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
스트레스 자극에 노출되었을 때 인체가 버텨내는 탄력성과 말초 혈관의 수축·이완 유연성을 평가하여 회복 잠재력을 측정합니다.
</p>
</div>
</div>


<!-- 2. 섹션 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
2. 해아림한의원 대구본점의 자율신경 다각 진단 프로토콜
</h2>

<p>
해아림한의원에서는 HRV 단독 측정에 그치지 않고, <strong>적외선 체열 검사(상열하한 체열 지도)</strong>, <strong>뇌파(EEG) 과각성도 측정</strong>, <strong>기립 체위 변동 검사</strong>, 그리고 <strong>사상체질 맥진</strong>을 융합하여 환자 신체의 전인적인 불균형 뿌리를 입체적으로 찾아냅니다. 검사는 전극 패치를 부착하는 방식으로 아프거나 불편함이 전혀 없어 노약자도 편안하게 받으실 수 있습니다.
</p>


<!-- 3. 자주 묻는 질문 FAQ -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
자주 묻는 핵심 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">

<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. 검사 당일 커피나 에너지 음료를 마셔도 되나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 카페인은 교감신경을 일시적으로 과흥분시키므로, 정확한 기저 자율신경 상태를 측정하기 위해 검사 당일은 커피, 녹차, 에너지 음료 복용을 삼가시는 것이 좋습니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 검사 시간은 총 얼마나 소요되나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 문진표 작성과 HRV 측정, 체열 검사 및 원장님 1:1 심층 결과 상담까지 약 40분에서 1시간 정도 소요됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 기존에 복용 중인 혈압약이나 위장약이 결과에 영향을 주나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 혈압약이나 위장약은 평소대로 복용하고 내원하시면 되며, 문진 시 복용 약물을 의료진에게 알려주시면 약물 효과를 감안하여 정밀 판독합니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 수치가 나쁘게 나오면 정상으로 회복될 수 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 자율신경은 고정된 뼈가 아니라 신경의 조율 기능이므로, 과열을 끄는 체질 탕약과 이완 치료를 통해 정상적인 밸런스로 충분히 회복됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 검사 결과를 당일 바로 확인할 수 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 네, 검사 종료 즉시 컴퓨터 알고리즘 분석 리포트가 출력되며, 김대억 대표원장이 직접 그래프를 짚어가며 1:1로 설명해 드립니다.
</div>
</details>
