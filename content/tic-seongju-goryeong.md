<p style="margin: 0; font-size: 0.95rem; color: #475569;">

⚠️ 조기 발견이 중요한 틱장애의 4가지 동반 신호
</h3>
<ul style="padding-left: 20px; margin: 0 0 16px; color: #475569; font-size: 0.98rem; line-height: 1.8;">
<li><strong>신체 떨림 및 근육 경련:</strong> 눈 깜빡임, 어깨 으쓱임, 배에 불필요하게 힘을 주거나 팔다리를 튕기는 운동틱</li>
<li><strong>소리 조절 이상(음성틱):</strong> 헛기침(음음·큼큼), 괴성, 콧소리 킁킁거림 등 본인 의지와 상관없이 터져 나오는 소리</li>
<li><strong>주의집중력 저하(ADHD 동반):</strong> 수업 시간 집중이 어렵고 몸을 가만히 두지 못하며 충동적인 행동을 보이는 양상</li>
<li><strong>정서적 위축 및 교우 불안:</strong> 친구들의 놀림이나 지적에 위축되어 자존감이 낮아지고 학교 등교를 거부하는 현상</li>
</ul>

3. 성주·고령 부모님들이 자주 묻는 질문 BEST 3

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 아이가 틱 증상을 보일 때 집에서 부모는 어떻게 반응해야 하나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 가장 중요한 양육 원칙은 아이의 증상을 지적하거나 "하지 말라"고 다그치지 않는 것입니다. 틱은 참으려고 애쓸수록 뇌 기저핵에 과부하가 걸려 긴장이 끝나면 더욱 심하게 터져 나옵니다. 증상 자체는 모른 척 자연스럽게 넘어가 주시고, 아이가 과도한 스트레스나 스마트폰 자극에 노출되지 않도록 환경을 조율해 주시는 것이 좋습니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 틱장애와 함께 산만함(ADHD)이나 예민한 불안 증세가 같이 있는데 동시에 치료되나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 동시에 치료 가능하며 함께 다루어야 완치율이 높습니다. 틱과 ADHD는 모두 뇌 전두엽-기저핵-시상 회로의 신경 조절 미숙이라는 공통된 뿌리를 공유합니다. 해아림에서는 불필요한 운동 신호를 가라앉히는 동시에 전두엽의 주의집중력을 보강하는 1:1 맞춤 한약과 두뇌 훈련을 병행하여 두 질환을 유기적으로 치료합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q3. 성주나 고령(다산 등)에서 자가용으로 방문할 때 주차와 예약은 어떻게 하나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 성주 및 고령 다산 방면에서는 달구벌대로 직통 또는 고속도로를 통해 약 30~40분 내외로 범어역 사거리 두산위브더제니스에 도착하실 수 있습니다. 상가 전용 지하 대형 주차장에 주차하시면 2시간 무료 주차가 지원됩니다. 아이들의 세밀한 1:1 심층 진료를 위해 사전 전화(053-751-0071) 또는 네이버 예약으로 예약 후 방문해 주시면 대기 없이 편안한 상담이 가능합니다.
</p>
