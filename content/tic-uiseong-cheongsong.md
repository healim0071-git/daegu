3. 의성·청송 틱장애 환자분들이 자주 묻는 질문 BEST 3

<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 의성이나 청송에서 거리가 다소 먼데, 매주 방문하지 않고도 치료 효과를 볼 수 있나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 충분히 가능합니다. 첫 진료 시 정밀 뇌기능 검사와 한방신경정신과 박사 원장님의 심층 진단을 철저히 진행한 후, 아이의 증상과 체질에 맞춘 한약 처방을 집중 복용하도록 합니다. 이후 2~3주에 1회 주말(토요일 오후 4시까지 연속 진료)을 활용해 내원하시며, 내원 사이에는 유선 상담으로 복용 상태와 증상 변화를 세밀히 모니터링하여 원거리에서도 안정적인 호전을 이끌어냅니다.
</p>

<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 헛기침(음음, 큼큼)이나 코 킁킁거림이 비염 치료를 오래 받아도 낫지 않는데 음성틱인가요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 비염 치료에도 호전이 없다면 음성틱일 가능성이 매우 높습니다. 비염이나 후비루 증상으로 시작되었다가 뇌 신경계의 과민 반응이 고착화되어 습관성 헛기침이나 킁킁거림으로 이어지는 경우가 많습니다. 특히 잠들기 전이나 긴장할 때 소리가 더 커지고, 말을 할 때는 잠시 멈춘다면 음성틱으로 진단하고 뇌 신경 조율 치료를 시작해야 합니다.
</p>

<p style="margin: 0; font-size: 0.95rem; color: #475569;">
