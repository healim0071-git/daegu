<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
3. 칠곡 자율신경실조증 환자분들이 가장 많이 질문하시는 BEST 3
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">

<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 내과나 신경과 검사에서 정상인데 왜 몸은 계속 아플까요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 혈액검사, 위내시경, 심전도, 뇌 MRI 등은 장기의 '구조적 파괴나 종양'을 찾아내는 검사입니다. 자율신경실조증은 장기 자체의 고장이 아니라, 장기를 자율적으로 조절하는 '신경 신호 체계(소프트웨어)'에 오작동이 생긴 질환이므로 형태학적 검사에서는 정상으로 나타납니다. 해아림에서는 HRV 검사를 통해 신경계 조절 기능을 명확히 진단합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 칠곡에서 통원하려면 얼마나 자주 방문해야 하나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 왜관역에서 기차로 20분, 자가용으로 30분대 거리로 내원이 수월합니다. 자율신경 치료는 매일 침을 맞는 것보다 맞춤 한약 복용을 중심으로 주 1회 또는 격주 1회 내원하여 두개천골요법과 침구 치료를 받는 것이 훨씬 효과적이므로 직장인분들도 부담 없이 회복에 집중하실 수 있습니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q3. 신경안정제나 위장약 없이 한방으로 완치가 가능한가요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 가능합니다. 증상 억제제(위산분비억제제, 신경안정제)는 약효가 떨어지면 증상이 재발하지만, 한방 치료는 뇌 시상하부-자율신경계의 자생력을 강화하여 신체 스스로 심박수와 위장 운동, 체온을 정상 조율하도록 훈련시킵니다. 뇌신경계 자생력이 회복되면 약물 의존 없이 온전한 일상으로 복귀하실 수 있습니다.
</p>
