<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
4. 대구 공황장애 정신과 질환 진료 전 꼭 확인해야 할 Q&amp;A
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 한의원에서 공황장애 같은 정신과 질환을 치료하면 진료 기록(F코드)이 남지 않나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 한의원 진료는 일반 양방 정신건강의학과와 건강보험 청구 및 질병 분류 체계가 다릅니다. 향정신성의약품 처방 이력이나 정신과 F코드 기록에 대한 부담 없이, 100% 사전 예약제를 통해 개인 프라이버시를 보호받으며 편안하게 신경계 치료에 집중하실 수 있습니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 발작이 없는 평소에도 늘 가슴이 조마조마하고 소화가 안 되는데 왜 그럴까요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 급성 공황발작이 지나간 자리에도 뇌가 언제 다시 위기가 닥칠지 몰라 교감신경의 긴장 끈을 놓지 못하는 '만성 예기불안'과 '범불안'이 남아 있기 때문입니다. 교감신경이 상시 항진되면 위장관 운동을 주관하는 미주신경이 억제되어 만성 소화불량, 명치 막힘, 어지럼증이 이어지므로 자율신경 균형을 함께 회복해야 합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q3. 내가 진짜 공황장애인지, 일시적인 스트레스 증상인지 모를 때도 내원해도 되나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 물론입니다. 오히려 회피 행동이 굳어지기 전인 초기 의심 단계에 자율신경(HRV) 및 뇌기능 검사를 통해 현재 내 신경계의 과각성 수준을 객관적으로 점검하는 것이 만성화를 예방하는 가장 빠른 길입니다.
</p>
