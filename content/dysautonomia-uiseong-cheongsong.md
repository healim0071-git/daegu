2. 한의학으로 풀어보는 자율신경실조증의 4대 원인과 4단계 솔루션

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 22px 24px; margin-bottom: 24px;">
<h3 style="font-size: 1.12rem; font-weight: 800; color: #0C4349; margin-top: 0; margin-bottom: 12px;">
🔍 한의학의 자율신경 불균형 4대 변증
</h3>
<ul style="padding-left: 20px; margin: 0 0 16px; color: #475569; font-size: 0.98rem; line-height: 1.8;">
<li><strong>음허화왕(陰虛火旺):</strong> 진액이 고갈되어 허화(虛火)가 상체로 뻗치며 얼굴 화끈거림, 식은땀, 야간 불면, 가슴 두근거림 유발</li>
<li><strong>심비양허(心脾兩虛):</strong> 비위 소화기와 심장이 약해져 만성 소화불량, 무기력증, 어지럼증, 사소한 걱정이 꼬리를 무는 상태</li>
<li><strong>간기울결(肝氣鬱結):</strong> 오랜 화병과 스트레스로 기운이 뭉쳐 가슴이 답답하고 한숨을 자주 쉬며 목에 이물감이 걸리는 증상</li>
<li><strong>신양허(腎陽虛):</strong> 하초(하체)의 양기가 식어 손발과 아랫배가 차갑고 소변이 잦으며 기립 시 핑 도는 기립성 조절 장애</li>
</ul>

<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 온몸이 다 아픈데 병원 검사에서는 왜 아무 이상이 없다고 하나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 일반 정밀 검사는 궤양이나 염증, 종양 같은 '형태적 이상'을 확인하는 검사입니다. 자율신경실조증은 오장육부를 무의식적으로 조율하는 '신경 조절 기능'이 고장 난 상태이므로 형태학적 검사에서는 정상으로 나타납니다. 해아림에서는 HRV 검사를 통해 신경계 조절력을 정밀 진단하여 원인을 규명합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 의성·청송에서 통원할 때 진료 주기와 관리는 어떻게 되나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 첫 내원 시 대표원장과의 정밀 검사와 심층 상담을 거쳐 체질 맞춤 한약을 처방합니다. 이후 원거리 환자분들은 2~4주에 1회 내원하시거나 정기적인 비대면 상담을 통해 경과를 세밀하게 관리해 드리므로 장거리 이동에 대한 부담 없이 치료를 이어가실 수 있습니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q3. 고혈압약, 당뇨약 등 기존에 먹던 양약과 함께 한약을 복용해도 안전한가요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 안전합니다. 복용 중이신 양약 처방전을 사전 확인하여 상호작용이 없는 안전한 약재들로 맞춤 조제하며, 양약과 30분~1시간가량 간격을 두고 복용하시도록 체계적으로 지도해 드립니다.
</p>
