<p style="margin: 6px 0 0; font-size: 0.95rem; color: #475569;">
기질적 장기 손상이 아니라, 뇌신경계와 자율신경계가 과도하게 흥분하여 내장 감각을 비정상적으로 예민하게 만들기 때문입니다. 한의학에서는 이를 기울(氣鬱)과 신경성 담음으로 진단하여 뇌신경 긴장을 완화함으로써 신체 증상을 말끔히 해소합니다.
</p>
</div>

<p style="margin: 6px 0 0; font-size: 0.95rem; color: #475569;">

</p>
</div>

<p style="margin: 6px 0 0; font-size: 0.95rem; color: #475569;">
해아림의 모든 약재는 중금속과 잔류농약 검사를 철저히 거친 식약처 인증 규격품 한약재만을 사용합니다. 환자의 위장 기능과 체질에 맞추어 처방되므로 속 쓰림 없이 편안하게 복용하실 수 있습니다.
