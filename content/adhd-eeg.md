아이의 산만함과 충동성, 주의력 결핍은 눈에 보이는 겉 행동일 뿐이며, 그 근본적인 뿌리는 <strong>뇌 신경세포들이 주고받는 미세한 전기 신호인 '뇌파(EEG)'의 불균형</strong>에 있습니다.<br>
ADHD를 겪는 아이들의 전두엽에서는 주의 집중을 유지하는 고주파 뇌파(베타파)가 부족하고, 멍하게 잠에 빠져들 때 나오는 느린 저주파 뇌파(세타파)가 비정상적으로 과다 방출되는 신경학적 특징이 나타납니다. <strong>대구 ADHD 뇌파검사</strong>는 이러한 두뇌 신경생리학적 이상을 시각적인 데이터로 정량화하여 오진을 방지하고 가장 적합한 1:1 두뇌 훈련(뉴로피드백)을 처방하는 결정적인 나침반 역할을 합니다.

<!-- 1. ADHD 뇌파의 핵심: 세타/베타 비율(TBR)의 비밀 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. ADHD 뇌파의 핵심 지표: 세타파(Theta)와 베타파(Beta)의 불균형
</h2>

<p>
미국 FDA(식품의약국)에서도 ADHD 보조 진단 지표로 승인한 바 있는 <strong>세타/베타 비율(Theta/Beta Ratio, TBR)</strong>은 두뇌가 깨어있는 각성 상태를 얼마나 안정적으로 유지하고 있는지를 보여주는 핵심 지표입니다.
</p>

<!-- 뇌파 유형 비교 카드 -->
<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin-bottom: 28px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">느린 서파: 세타파 (Theta, 4~8Hz) 과다</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
졸음이 오거나 멍하니 공상에 빠질 때 나타나는 뇌파입니다. ADHD 아동은 공부하거나 지시를 들을 때 이 세타파가 과도하게 쏟아져 나와 <strong>머릿속이 안개 낀 듯 멍해지고(Brain fog), 지시를 끝까지 기억하지 못하는 원인</strong>이 됩니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">집중파: 베타파 (Beta, 13~30Hz) 결핍</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
문제를 해결하고 능동적으로 집중할 때 가동되는 고주파 뇌파입니다. ADHD 뇌에서는 전두엽 부위의 베타파와 SMR(감각운동리듬)파의 출현이 억제되어 있어 <strong>스스로 지루함을 견디고 집중을 유지하는 추진력이 부족</strong>해집니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">좌우 전두엽 뇌파 비대칭과 감정 조절</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
좌측 전두엽은 긍정적 접근 동기를, 우측 전두엽은 회피와 불안을 조율합니다. 좌우 뇌파의 균형이 깨지면 충동적 분노 폭발, 사소한 지적에도 지나친 좌절과 거부 반응을 보이게 됩니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">고각성 High-Beta파와 틱·불안 동반</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
일부 ADHD 아동은 긴장과 스트레스로 인해 30Hz 이상의 고각성 하이베타파가 폭주합니다. 이 경우 일반적인 ADHD 약물(각성제)을 복용하면 틱장애나 야간 불면증이 격발될 위험이 매우 높습니다.
</p>
</div>
</div>

<!-- 2. 뇌파검사는 어떻게 진행되나요? -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
2. 해아림한의원 대구본점 뇌파검사 진행 과정 및 안전성
</h2>

<div style="background: #F8FAFB; border: 1.5px solid #E2E8F0; border-radius: 12px; padding: 22px; margin-bottom: 24px;">
<p style="margin: 0 0 14px; font-weight: 700; color: #0C4349;">
💡 아이가 아프지 않을까 걱정하지 마세요 (100% 비침습 무통 검사)
</p>
<p style="margin: 0 0 16px; color: #475569; font-size: 0.95rem;">
뇌파검사는 머리에 어떠한 전기나 물리적 자극을 주는 것이 아니라, 두피 표면에 부착된 초정밀 센서를 통해 <strong>뇌에서 자연스럽게 발생하는 미세한 전기 신호만을 읽어내는(수신하는) 검사</strong>입니다. 주사나 방사선 노출이 전혀 없어 영유아도 안전하고 편안하게 검사를 받을 수 있습니다.
</p>
<ul style="margin: 0; padding-left: 20px; color: #334155; line-height: 1.8;">
<li><strong>준비 단계:</strong> 편안한 리클라이너 소파에 앉아 두피 부위에 친환경 전도 겔을 소량 도포하고 센서를 부착합니다.</li>
<li><strong>휴식기 뇌파 측정:</strong> 눈을 감은 상태(폐안)와 눈을 뜬 상태(개안)에서 두뇌의 기저 안정 뇌파를 각각 3~5분간 기록합니다.</li>
<li><strong>과제 수행 뇌파 측정:</strong> 화면을 응시하며 주의 집중이 요구되는 상황에서 전두엽 뇌파가 적절히 전환되는지 관찰합니다.</li>
<li><strong>데이터 분석 및 리포트 도출:</strong> 컴퓨터 알고리즘을 통해 주파수 대역별 파워 스펙트럼과 뇌기능 맵을 시각화합니다.</li>
</ul>
</div>

<!-- 3. 뇌파 검사 결과를 바탕으로 한 맞춤 뉴로피드백 훈련 연계 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
3. 뇌파검사 결과는 어떻게 치료(뉴로피드백)로 이어지나요?
</h2>

<p>
뇌파검사의 궁극적인 목적은 단순히 'ADHD인가 아닌가'를 판별하는 것에 그치지 않고, <strong>우리 아이 두뇌의 취약한 주파수를 찾아내어 스스로 조절하도록 훈련하는 '뉴로피드백(Neurofeedback)' 프로그램을 맞춤 설계</strong>하는 데 있습니다.
</p>

<div style="background: #EFF8F9; border-left: 4px solid #146369; padding: 18px 20px; border-radius: 0 10px 10px 0; margin: 20px 0;">
<p style="margin: 0; font-weight: 800; color: #0C4349; font-size: 1.03rem;">
🎮 게임을 하듯 스스로 뇌를 훈련하는 뉴로피드백의 원리
</p>
<p style="margin: 8px 0 0; color: #475569; font-size: 0.95rem; line-height: 1.7;">
아이가 뇌파 센서를 착용한 채 모니터 화면 속 자동차 경주나 우주선 비행 게임을 진행합니다. 아이가 멍하니 딴생각을 하거나 산만해져 <strong>세타파가 올라가면 화면이 멈추거나 어두워지고</strong>, 스스로 집중하여 <strong>안정된 집중 뇌파(SMR/베타파)를 뿜어내면 자동차가 쾌속 질주하고 점수를 얻게</strong> 됩니다. 이 과정을 반복하면서 뇌는 외부 약물 없이도 스스로 집중 상태를 유지하는 신경가소성(Neuroplasticity) 회로를 튼튼하게 강화합니다.
</p>
</div>

<!-- 4. 자주 묻는 질문 FAQ -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
4. 대구 ADHD 뇌파검사 자주 묻는 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. 뇌파검사 당일 주의해야 할 사항이 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 두피에 유분이나 헤어 스프레이, 젤 등이 묻어 있으면 전기 신호 수신에 저항이 발생할 수 있으므로, 검사 당일 아침 샴푸로 머리를 깨끗이 감고 완전히 말린 후 내원하시는 것이 좋습니다. 또한 전날 밤 충분한 수면을 취하는 것이 정확한 뇌파 측정에 도움이 됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 아이가 머리에 무언가를 씌우는 것을 무서워하거나 가만히 있지 못하면 어쩌죠?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 소아청소년 진료 경험이 풍부한 임상 인력이 아이의 눈높이에 맞춰 장비를 친근하게 설명하고 긴장을 충분히 풀어준 후 진행합니다. 강압적인 분위기가 아니라 게임이나 우주 탐험을 하듯 즐겁고 편안한 분위기 속에서 검사가 이루어지므로 크게 걱정하지 않으셔도 됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 대학병원 뇌파검사(수면뇌파)와 한의원 뇌파검사의 차이는 무엇인가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 대학병원 신경과의 뇌파검사는 주로 뇌전증(간질) 발작파나 기질적 뇌 손상을 감별하기 위한 목적이 큽니다. 반면 본원의 뇌파검사는 주의력 결핍, 인지 과제 수행 시의 전두엽 기능 저하, 각성 리듬 조절력 등 두뇌의 '기능적 인지 효율성'을 평가하고 치료 훈련에 직접 연계하는 기능성 뇌파 분석입니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 성인 ADHD도 뇌파검사로 확인이 가능한가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 네, 매우 유용합니다. 성인의 경우 겉으로는 과잉행동이 사라져 보이지만, 뇌파를 측정해보면 직무 스트레스나 업무 몰입 시 전두엽의 세타파 억제가 이루어지지 않거나 만성 피로로 인한 알파파 고갈 등이 뚜렷하게 관찰됩니다. 직장 생활의 업무 효율 개선을 위한 맞춤 솔루션을 얻으실 수 있습니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 뇌파검사 결과는 당일 바로 들을 수 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 네, 검사 직후 전산 분석 프로그램을 통해 결과 리포트가 즉각 생성되며, 한방신경정신과 박사 김대억 대표원장이 부모님(또는 환자 본인)과 함께 모니터를 보며 뇌파 그래프와 주의력 지표를 알기 쉽게 설명해 드립니다.
</div>
</details>
