<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. 대구 ADHD 정밀 검사의 핵심: 주관적 평가와 객관적 데이터의 통합
</h2>

<p>
일부 기관에서는 부모님 설문지 몇 장만으로 섣불리 약물 처방을 권유하기도 합니다. 하지만 아이들은 환경에 따라 행동 양상이 크게 달라지며, 불안이나 스트레스로 인한 일시적 산만함이 ADHD로 오인되는 경우도 적지 않습니다. 따라서 다음과 같은 다각적 검사가 결합되어야 합니다.
</p>

<!-- 검사 비교 그리드 -->
<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin-bottom: 28px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">① 환경별 다면 평가 (부모·교사 척도)</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
미국소아과학회(AAP) 진단 기준에 따라 가정과 학교 등 최소 2곳 이상의 환경에서 산만함과 충동성이 일관되게 나타나는지 교사 행동 평정 척도와 부모 관찰 기록을 대조 분석합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">② 전산화 주의력 연속수행검사 (CAT / CPT)</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
컴퓨터 모니터와 청각 자극에 대한 반응 속도와 오류율을 측정하여 단순주의력, 선택주의력, 지속주의력, 작업기억력의 저하 수준을 또래 표준 집단 데이터와 정량적으로 비교합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">③ 뇌신경계 스트레스 &amp; 자율신경 검사 (HRV)</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
심박변이도(HRV) 측정을 통해 교감신경의 과도한 흥분도와 부교감신경의 이완력을 평가하여, 아이의 산만함이 과잉 각성 때문인지 만성 피로와 번아웃 때문인지 감별합니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.05rem; font-weight: 800; color: #146369; margin-bottom: 8px;">④ 한의학적 사상체질 및 장부 기혈 변증</div>
<p style="margin: 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
두뇌로 공급되는 혈류 순환 상태와 심열(心熱), 간양상항(肝陽上亢), 담음(痰飲) 등 체질적 불균형 요인을 맥진과 설진으로 정밀 감별하여 맞춤 치료 처방의 근거를 마련합니다.
</p>
</div>

2. 해아림한의원 대구본점 ADHD 정밀 검사 6단계 절차
</h2>

<div style="background: #F1F7F8; border-radius: 12px; padding: 22px; margin-bottom: 24px;">
<div style="display: flex; flex-direction: column; gap: 14px;">
<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">1단계: 사전 설문 및 발달력 심층 문진</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
출생 과정, 영유아기 수면과 감각 발달, 유치원·초등학교 입학 후 교우 관계 및 학업 성취도 추이를 면밀히 청취합니다.
</p>
</div>

<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">2단계: 시·청각 주의력 종합검사 (CAT)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
아이가 모니터 화면과 헤드폰을 통해 제시되는 자극에 얼마나 빠르고 정확하게 반응하며, 충동성을 제어하는지 측정합니다.
</p>
</div>

<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">3단계: 두뇌 뇌파(EEG) 및 각성도 검사</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
전두엽 부위의 세타파(느린 서파)와 베타파(주의집중파)의 비율을 측정하여 두뇌가 각성 상태를 유지하는 힘을 객관화합니다.
</p>
</div>

<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">4단계: 자율신경계 스트레스 저항도 검사 (HRV)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
교감신경의 긴장도와 신체 활력도를 측정하여 만성 학업 스트레스나 긴장성 피로가 주의력에 미치는 영향을 파악합니다.
</p>
</div>

<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">5단계: 동반 질환 정밀 감별 (틱, 수면, 정서)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
눈 깜빡임이나 헛기침 등 틱 증상, 야간 입면 지연, 불안 및 적대적 반항 성향의 동반 여부를 종합 진단합니다.
</p>
</div>

<div style="background: #FFFFFF; border-left: 4px solid #146369; padding: 14px 16px; border-radius: 0 8px 8px 0;">
<strong style="color: #0C4349; font-size: 1.02rem;">6단계: 한방신경정신과 박사 1:1 결과 상담</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">
검사 결과 그래프를 부모님께 투명하게 설명해 드리며, 향후 예후와 맞춤 한방 치료 및 가정 내 훈육 가이드를 설계합니다.
</p>
</div>
</div>

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
4. 대구 ADHD 검사에 대해 자주 묻는 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. ADHD 검사는 몇 살부터 가능한가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 표준화된 컴퓨터 연속수행검사(CAT)는 만 4~5세(학령전기)부터 가능합니다. 다만 초등학교 입학 전후인 만 6~8세경 단체 생활과 규칙 준수가 요구되는 시기에 검사를 진행할 때 가장 정확한 진단과 조기 개입 효과를 거둘 수 있습니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 검사 소요 시간은 얼마나 걸리나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 문진표 작성, 컴퓨터 주의력 연속수행검사, 뇌파 및 자율신경 검사, 그리고 대표원장 1:1 심층 상담까지 포함하여 약 1시간에서 1시간 30분 정도 소요됩니다. 100% 전화 예약제로 대기 없이 편안하게 진행됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 한의원 ADHD 검사도 병원 기록에 남나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 본원의 검사와 진료는 철저한 의료법상 개인정보 보호 규정을 준수합니다. 정신과 F코드 등 외부로 공개되는 정신과 약물 복용 기록이 남지 않으므로, 향후 진학이나 보험 가입, 취업 시 불이익을 염려하지 않으셔도 됩니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 아이가 검사 당일 긴장하거나 낯을 많이 가리면 결과에 지장이 없나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 아이들의 긴장 상태를 고려하여 편안하고 따뜻한 환경에서 연습 문항을 충분히 거친 후 본 검사를 시행합니다. 또한 단일 검사 점수에만 의존하지 않고 발달력과 환경 요인을 종합적으로 교차 검증하므로 신뢰도 높은 진단이 가능합니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 성인인데 어릴 적 ADHD 진단을 받은 적이 없어도 검사를 받을 수 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 네, 가능합니다. 어릴 때는 얌전하거나 지능으로 결함을 보완해 오다가 성인이 되어 복잡한 멀티태스킹이나 시간 관리가 요구되는 직장 환경에서 뒤늦게 발견되는 성인 ADHD 환자분들이 매우 많습니다. 객관적 검사로 원인을 파악하면 일상의 능률이 크게 개선됩니다.
</div>
</details>
