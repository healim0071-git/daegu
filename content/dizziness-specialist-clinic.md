<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. 어지럼증 잘 보는 병원을 선택하는 4가지 기준
</h2>

<div class="tic-grid-2col" style="margin: 18px 0;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349;">① 회전성과 비회전성의 명확한 감별</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #64748B;">귀의 전정기관 문제(이석증, 메니에르)인지, 뇌혈류 및 자율신경 실조(PPPD, 기립성 저혈압)인지 정확히 구별합니다.</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349;">② 검사상 정상인 만성 어지럼의 해결 능력</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #64748B;">MRI나 CT에서 이상이 나타나지 않는 기능성 신경 과민과 뇌 피로 상태를 진단하고 치료할 수 있어야 합니다.</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349;">③ 뇌 평형 신경망 자생력 강화 프로그램</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #64748B;">증상만 일시적으로 마취시키는 약이 아니라 시선 고정 훈련, 전정 재활, 뇌혈류 탕약으로 뇌 스스로 균형을 잡게 돕습니다.</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349;">④ 1:1 심층 진료 시간 확보</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #64748B;">3분 진료로 끝내지 않고 환자의 발병 배경, 수면 상태, 스트레스 이력까지 면밀히 듣고 치료 계획을 수립합니다.</p>
</div>
</div>

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
2. 해아림한의원 대구본점이 신뢰받는 이유
</h2>

<p>
해아림한의원 대구본점은 16년간 어지럼증 환자분들의 임상 데이터를 축적해왔습니다. 뇌파(EEG), 자율신경(HRV), 롬베르그 균형 검사 등 다각적 평가를 바탕으로 <strong>한방신경정신과 박사 김대억 대표원장</strong>이 맞춤 한약과 두경부 추나요법, 침구 치료를 유기적으로 결합하여 높은 치료 만족도를 실현하고 있습니다.
</p>

<!-- 3. 자주 묻는 질문 FAQ -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
자주 묻는 핵심 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. 어지럼증 치료 시 신경안정제를 계속 먹어야 하나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
아닙니다. 초기 급성 발작기에는 양방 진정제가 도움될 수 있으나, 장기 복용 시 뇌의 전정 보상 기능을 오히려 억제할 수 있습니다. 해아림에서는 뇌 스스로 균형을 조절하도록 자생력을 회복시켜 서서히 약물에 의존하지 않도록 돕습니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 어지럼증 잘 보는 병원에서 치료받으면 보통 몇 회 정도 내원하나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
증상의 만성화 정도에 따라 다르지만, 일반적으로 주 1~2회 침구·추나 치료와 함께 1~3개월간 맞춤 한약을 복용하며 뇌신경망의 평형성을 안정화합니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 이석증 치료 후에도 남아있는 어지럼증도 호전될 수 있나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
네, 매우 많은 분들이 이석증 후 잔여 현기증(멍함, 구름 위를 걷는 느낌)으로 내원하십니다. 이는 내이 림프 순환과 뇌간 전정신경핵의 회복을 촉진하는 한약과 전정 재활 치료를 통해 빠르게 개선됩니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 이비인후과나 신경과 검사 기록지를 가져가야 하나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
네, 기존에 촬영하신 뇌 MRI, MRA 결과지나 전정기능 검사 결과지를 지참하시면 중복 검사를 방지하고 진단의 정확도를 높이는 데 큰 도움이 됩니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 자동차를 운전해서 방문하기 편한가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
네. 대구 범어역 두산위브 더제니스 상가 지하 대형 주차장을 완비하고 있어 주차가 매우 편리하며, 진료 환자분께는 2시간 무료 주차권을 제공해 드립니다.
</div>
</details>
