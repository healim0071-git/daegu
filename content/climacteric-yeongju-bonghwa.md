<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin-bottom: 28px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.04);">
<div style="font-size: 1.08rem; font-weight: 800; color: #146369; margin-bottom: 8px;">① 한방신경정신과 박사의 1:1 심층 진료</div>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">

</p>

</p>

<!-- 2. 갱년기 증후군 핵심 6대 증상군 요약 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
2. 갱년기 증후군 핵심 6대 증상군 요약
</h2>
<p style="margin-bottom: 16px;">
갱년기 증상은 여성마다 매우 다양하게 나타납니다. 해아림한의원 대구본점에서는 다음 6가지 핵심 영역으로 분류하여 원인별 진료를 진행합니다.
</p>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 14px; margin-bottom: 30px;">
<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">① 혈관운동성 장애 (안면홍조·상열감·야간발한)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">얼굴과 목, 상체로 뜨거운 열이 치솟고 땀이 비 오듯 쏟아지며, 곧이어 오한이 드는 시상하부 체온조절 오작동 증상입니다.</p>
</div>

<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">② 수면장애 (갱년기 불면증·야간각성)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">잠들기 힘든 입면장애, 식은땀과 두근거림으로 밤에 자주 깨는 수면유지장애, 새벽에 일찍 깨어 피로가 풀리지 않는 조기각성입니다.</p>
</div>

<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">③ 정서 및 신경정신과적 증상 (우울·불안·가슴두근거림)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">이유 없는 불안감, 가슴 두근거림(심계항진), 감정 기복, 눈물이 왈칵 쏟아지는 우울감, 사소한 자극에도 화가 치미는 화병 증상입니다.</p>
</div>

<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">④ 근골격계 통증 (관절통·근육통·뻣뻣함)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">손가락 마디마디가 쑤시고 아침마다 손발이 뻣뻣하며, 무릎, 어깨, 허리 등 전신 다발성 통증과 림프 순환 장애가 동반됩니다.</p>
</div>

<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">⑤ 자율신경실조 증상 (어지럼증·두통·소화불량)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">교감신경 항진으로 인한 잦은 어지럼증, 긴장성 두통, 속이 메스껍고 더부룩한 만성 소화불량, 손발 차가움(수족냉증)입니다.</p>
</div>

<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 16px;">
<strong style="color: #0C4349; font-size: 1.05rem;">⑥ 인지 기능 변화 (뇌피로·브레인 포그·건망증)</strong>
<p style="margin: 6px 0 0; font-size: 0.93rem; color: #475569;">머리가 안개 낀 듯 멍하고 집중력이 떨어지며, 방금 하려던 말이 생각나지 않는 건망증과 심각한 만성 피로감입니다.</p>
</div>
</div>

<!-- 3. 호르몬 대체요법(HRT)이 고민될 때, 한의학적 진료의 차별점 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
3. 호르몬 대체요법(HRT)이 여러 이유로 고민될 때
</h2>
<div style="background: #FFFFFF; border: 1.5px solid #E2E8F0; border-radius: 12px; padding: 22px; margin-bottom: 28px;">
<p style="margin: 0 0 14px; color: #334155; line-height: 1.75;">
유방암, 자궁내막 질환 등의 가족력이 있거나, 혈전 위험 또는 호르몬제 복용 후 나타나는 체중 증가, 부종, 유방통 등의 우려로 <strong>호르몬 대체요법(HRT) 진행이 망설여지시는 분들</strong>이 많습니다.<br><br>
해아림한의원의 치료는 인위적인 호르몬 주입이 아니라, <strong>몸 스스로 호르몬 변화에 적응하도록 완충 능력과 회복탄력성을 길러주는 방식</strong>입니다. 신장(腎臟)의 음혈(陰血)을 보충하여 상열감을 가라앉히는 보음청열(補陰淸熱)과 자율신경 과각성을 진정시키는 청열안신(淸熱安神) 처방을 통해 치료 과정에서 <strong>신체 부담을 덜 수 있으며, 일상적인 컨디션과 수면의 질이 자연스럽게 안정</strong>되어 갑니다.
</p>

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
4. 해아림한의원 대구본점 갱년기 다층 검사 시스템
</h2>
<ol style="margin-left: 20px; padding-left: 0; color: #334155; margin-bottom: 24px;">
<li style="margin-bottom: 10px;"><strong>원인 분석 설문 작성:</strong> 신체화 증상, 안면홍조 빈도, 수면 상태 및 기저 질환 심층 조사</li>

<li style="margin-bottom: 10px;"><strong>갱년기 심리 평가 척도(KMI/BDI):</strong> 쿠퍼만 지수(KMI), 우울 척도, 불안 척도 종합 평가</li>
<li style="margin-bottom: 10px;"><strong>한의학적 4진(망·문·문·절):</strong> 맥진, 설진, 복진을 통한 간·신·심 음허화왕(陰虛火旺) 병리 감별</li>
<li style="margin-bottom: 10px;"><strong>김대억 대표원장 1:1 심층 상담:</strong> 검사 결과 통합 분석 및 환자별 1:1 개인 맞춤 치료 플랜 수립</li>
