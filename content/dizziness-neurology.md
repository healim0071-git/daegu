<p style="margin: 0 0 10px; color: #334155;">

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. 주요 신경과적 어지럼증 질환의 유형과 특징
</h2>

<div style="background: #FFFFFF; border: 1.5px solid #E2E8F0; border-radius: 12px; padding: 22px; margin: 18px 0; line-height: 1.8;">
<ul style="margin: 0; padding-left: 20px; color: #334155;">
<li><strong>지속성 체위-지각 어지럼증 (PPPD):</strong> 급성 어지럼이나 스트레스 이후 3개월 이상 지면이 흔들리거나 몸이 붕 뜨는 느낌이 지속되며, 마트나 복잡한 시각 자극에 노출될 때 악화됩니다.</li>
<li><strong>전정 편두통 (Vestibular Migraine):</strong> 편두통 병력이 있는 환자에게 어지럼증이 동반되는 질환으로, 머리가 지끈거리거나 묵직하면서 멀미, 구토, 빛과 소리에 대한 과민증이 나타납니다.</li>
<li><strong>척추뇌저동맥 혈류 부전:</strong> 뇌간과 소뇌로 혈액을 공급하는 척추동맥의 순환이 저하되어 뒷목 뻐근함과 함께 고개를 움직일 때 아찔함과 멍함이 발생합니다.</li>
<li><strong>중추성 응급 질환 감별:</strong> 발음 어눌함, 편측 마비, 심한 복시가 동반되는 뇌졸중은 즉각적인 상급병원 응급 진료가 필요합니다.</li>
</ul>
</div>

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
2. 해아림한의원의 신경과적 어지럼증 특화 치료
</h2>

<p>
해아림한의원 대구본점 김대억 원장(한방신경정신과 박사)은 뇌간 전정신경핵의 흥분도를 가라앉히는 <strong>진경안신(鎭痙安神) 한약</strong>과 뇌혈관의 혈류 장애를 개선하는 <strong>청혈활혈(淸血活血) 탕약</strong>을 처방합니다. 또한 뇌의 잘못된 평형 인식을 재학습시키는 두뇌 훈련과 경추 추나요법을 유기적으로 병행하여 신경과적 만성 어지럼을 안정시킵니다.
</p>

<!-- 3. 자주 묻는 질문 FAQ -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
자주 묻는 핵심 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. 지속성 체위-지각 어지럼증(PPPD)도 한방 치료로 호전되나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
네, 매우 효과적입니다. PPPD는 뇌 신경망이 과민해져 평형 감각을 비정상적으로 인식하는 기능성 질환이므로, 신경계를 안정시키고 뇌 자생력을 키우는 한방 치료가 매우 뛰어난 호전율을 보입니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 어지럼증과 함께 두통이 주기적으로 오는데 전정 편두통인가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
어지럼증과 함께 한쪽 머리가 쑤시거나 메스꺼움, 눈부심이 동반된다면 전정 편두통일 가능성이 높습니다. 뇌혈류를 안정시키고 뇌혈관의 과민 반응을 가라앉히는 한약 치료로 두통과 어지럼을 동시에 다스립니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 신경과에서 처방받은 어지럼증 약을 계속 먹어도 되나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
초기 급성기에는 신경과 약물이 증상을 줄여주지만, 수개월 이상 장기 복용하면 인지 기능 저하나 뇌의 전정 보상 억제를 유발할 수 있습니다. 한방 치료를 통해 뇌 자생력을 회복하며 점진적으로 양약을 줄여나갈 수 있습니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 응급 뇌경색이나 뇌출혈과 어떻게 구별하나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
갑자기 벼락 맞은 듯한 두통, 말이 꼬이거나 혀가 굳는 느낌, 한쪽 팔다리 마비, 사물이 두 개로 겹쳐 보이는 증상이 있다면 즉시 응급실로 가셔야 합니다. 이러한 신경학적 결손이 없다면 만성 기능성 어지럼증일 가능성이 높습니다.
</div>
</details>
<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 신경과 질환성 어지럼증의 치료 기간은 얼마나 걸리나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
보통 2~3개월의 체계적인 치료를 통해 신경계 과각성을 낮추고 정상적인 평형 감각을 복원하게 됩니다.
</div>
</details>
