<div class="cond-section">
<h2 class="cond-h2">불안장애란 무엇인가요? (정상 불안 vs 병적 불안)</h2>
<div style="line-height: 1.8; color: #334155; font-size: 1rem;">
<p>
불안은 위험이나 위기 상황에 대처하기 위해 누구나 느낄 수 있는 인체의 지극히 정상적인 방어 기전입니다. 중요한 시험이나 발표를 앞두고 가슴이 뛰고 긴장하는 것은 자연스러운 생리 반응입니다.
</p>
<div style="background: #F0FDF4; border-left: 4px solid #16A34A; padding: 14px 18px; border-radius: 0 8px 8px 0; margin: 16px 0; font-size: 0.96rem; color: #166534;">
<strong>💡 병적인 '불안장애(Anxiety Disorder)'의 의학적 진단 기준</strong><br>
특별한 위협이나 위험 상황이 없는데도 <strong>불안과 파국적 걱정이 지나치게 과도하고, 끊으려 해도 통제되지 않으며, 6개월 이상 만성적으로 지속되어 일상생활·직장·학업·대인관계에 심각한 기능 저하를 초래하는 상태</strong>를 말합니다.
</div>
<p>
불안장애는 만성적이고 광범위한 걱정이 지속되는 <strong>범불안장애(GAD)</strong>를 비롯하여, 대인관계 공포를 느끼는 <strong>사회불안장애</strong>, 극단적 공포 발작이 터지는 <strong>공황장애</strong> 등 다양한 형태로 발현되므로 정밀한 감별 진단이 필수적입니다.
</p>

<div class="cond-section">
<h2 class="cond-h2">불안장애와 공황장애는 어떻게 다른가요?</h2>
<div style="line-height: 1.8; color: #334155; font-size: 1rem;">
<p>
두 질환은 뇌의 편도체 과열이라는 공통점을 가지지만 증상의 발현 양상에서 뚜렷한 차이가 있습니다.
</p>
<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 10px; padding: 18px 20px; margin: 16px 0;">
<p style="margin: 0 0 10px; font-weight: 700; color: #0C4349;">🔍 영국 국립보건임상연구원(NICE) 가이드라인 기준 비교</p>
<ul style="margin: 0; padding-left: 20px; color: #475569; line-height: 1.8; font-size: 0.95rem;">
<li><strong>공황장애 (Panic Disorder)</strong>: 특별한 이유 없이 갑작스럽게 심장이 터질 듯 뛰고 숨이 막히며 "죽을 것 같다"는 극심한 발작이 10~20분간 폭발적으로 일어나는 급성 질환.</li>
<li><strong>범불안장애 (Generalized Anxiety Disorder)</strong>: 특정 사건에 국한되지 않고 일상생활 전반에 걸쳐 "어쩌지, 큰일 나면 어쩌지" 하는 만성적 걱정과 긴장이 하루 종일 잔잔하게 이어지는 상태.</li>
</ul>

<p>
