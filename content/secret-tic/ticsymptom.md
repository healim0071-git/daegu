<!-- 2. 틱 증상 핵심 분류: 운동틱 vs 음성틱 -->
<div class="cond-section">
<h2 class="cond-h2">틱 증상의 종류와 세부 분류 (운동틱 & 음성틱)</h2>
<div style="line-height: 1.8; color: #334155; font-size: 1rem; margin-bottom: 20px;">
<p>
틱 증상은 신체의 근육이 제어되지 않고 수축하는 <strong>운동틱(근육틱)</strong>과, 호흡기 및 발성 근육이 작용하여 특정 소리를 반복하는 <strong>음성틱</strong>으로 크게 구분됩니다. 각각 단순형과 복합형으로 단계적 발전 양상을 보입니다.
</p>
</div>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin-bottom: 24px;">
  <!-- 운동틱 카드 -->
  <div style="background: #FFFFFF; border: 1.5px solid #C4DCE8; border-radius: 12px; padding: 22px 20px;">
    <div style="background: #0C4349; color: #FFFFFF; display: inline-block; padding: 4px 12px; border-radius: 6px; font-size: 12px; font-weight: 800; margin-bottom: 12px;">운동틱 (근육틱)</div>
    <h3 style="font-size: 1.15rem; font-weight: 800; color: #0C4349; margin: 0 0 10px;">단순 운동틱 vs 복합 운동틱</h3>
    <ul style="padding-left: 20px; line-height: 1.7; font-size: 0.95rem; color: #334155; margin: 0;">
      <li><strong>단순 운동틱:</strong> 눈 깜빡임, 눈동자 치켜뜨기, 코 찡긋거리기, 입 벌리기, 고개 끄덕임, 어깨 으쓱하기</li>
      <li><strong>복합 운동틱:</strong> 자신이나 타인을 만지기, 제자리에서 껑충 뛰기, 물건 던지기, 신체 꼬기, 외설 행동(희귀)</li>
    </ul>
  </div>

  <!-- 음성틱 카드 -->
  <div style="background: #FFFFFF; border: 1.5px solid #C4DCE8; border-radius: 12px; padding: 22px 20px;">
    <div style="background: #2F6F8F; color: #FFFFFF; display: inline-block; padding: 4px 12px; border-radius: 6px; font-size: 12px; font-weight: 800; margin-bottom: 12px;">음성틱 (소리틱)</div>
    <h3 style="font-size: 1.15rem; font-weight: 800; color: #2F6F8F; margin: 0 0 10px;">단순 음성틱 vs 복합 음성틱</h3>
    <ul style="padding-left: 20px; line-height: 1.7; font-size: 0.95rem; color: #334155; margin: 0;">
      <li><strong>단순 음성틱:</strong> 킁킁 소리, 헛기침(음음), 목 가다듬는 소리, 가래 뱉는 소리, 바람 부는 소리</li>
      <li><strong>복합 음성틱:</strong> 상황에 맞지 않는 단어나 문장 반복, 상대방 말 따라하기(반향어), 욕설틱(희귀)</li>
    </ul>
  </div>
</div>

<div style="background: #FEF3C7; border-left: 4px solid #F59E0B; padding: 14px 18px; border-radius: 0 8px 8px 0; margin: 18px 0; font-size: 0.95rem; color: #92400E;">
<strong>⚠️ 전조감각충동(Premonitory Urge)의 이해</strong><br>
틱 증상이 나타나기 직전 환자는 목, 어깨, 눈 안쪽 등에서 <em>"간질거리거나 답답해서 움직이지 않으면 견딜 수 없는 찝찝한 불쾌감"</em>을 느낍니다. 틱을 하고 나면 잠시 해소되지만 이내 다시 불쾌감이 차오르며 반복됩니다.
</div>
</div>

<!-- 3. 단순 버릇과 틱 증상의 5가지 결정적 구별법 -->
<div class="cond-section">
<h2 class="cond-h2">틱 증상과 단순 나쁜 버릇의 5가지 구별법</h2>
<div style="background: #F8FAFB; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px 22px; line-height: 1.8; color: #334155; font-size: 0.98rem;">
<ol style="padding-left: 20px; margin: 0;">
  <li style="margin-bottom: 10px;"><strong>잠시 참을 수는 있지만 오래 지속하지 못합니다:</strong> 버릇은 의식하면 멈추지만, 틱은 참을수록 내적 긴장이 쌓여 한꺼번에 터져 나옵니다.</li>
  <li style="margin-bottom: 10px;"><strong>증상의 부위와 양상이 끊임없이 이동합니다:</strong> 눈 깜빡임으로 시작했다가 코 찡긋, 고개 흔들기, 킁킁 소리로 위치와 종류가 바뀝니다(Wandering pattern).</li>
  <li style="margin-bottom: 10px;"><strong>긴장, 흥분, 피로도에 따라 심해집니다:</strong> 시험 기간, 새 학기, 모니터 화면 시청 후 폭발적으로 증상이 증가합니다.</li>
  <li style="margin-bottom: 10px;"><strong>수면 중이나 극도의 안정 시에는 줄어듭니다:</strong> 뇌가 깊은 수면에 빠지면 틱 증상은 거의 사라지나, 잠들기 직전에는 매우 심해질 수 있습니다.</li>
  <li><strong>지적하면 더 심해집니다:</strong> 버릇은 꾸중하면 고쳐지지만, 틱은 지적받는 순간 불안도가 치솟아 증상이 배가됩니다.</li>
</ol>
