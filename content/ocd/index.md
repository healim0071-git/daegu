<h2 class="cond-h2">강박증(OCD)이란 무엇인가요?</h2>
<p>강박증(Obsessive-Compulsive Disorder)은 본인의 의지와 상관없이 원치 않는 생각, 충동, 이미지 등이 반복적으로 떠오르는 <strong>'강박사고(Obsession)'</strong>와, 이로 인해 유발되는 극심한 불안과 불쾌감을 해소하기 위해 특정 행동이나 정신적 행위를 억지로 되풀이하는 <strong>'강박행동(Compulsion)'</strong>을 특징으로 하는 신경정신 질환입니다.</p>
<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin: 18px 0;">
<div style="background: #fdfcf7; border: 1px solid #ebd494; border-radius: 8px; padding: 18px;">
<h3 style="color: #b7791f; margin-top: 0; font-size: 1.15rem; display: flex; align-items: center; gap: 6px;">
<span>🧠</span> 강박사고 (Obsession)
</h3>
<p style="font-size: 0.95rem; color: #4a5568; line-height: 1.6; margin-bottom: 0;">
원하지 않는데도 뇌리에 침투적으로 떠오르는 생각, 이미지, 충동입니다. 본인이 원해서 하는 생각이 아니며, 오히려 그런 생각이 떠오르는 것 자체를 혐오하고 괴로워합니다. (오염 공포, 질병 걱정, 문 잠금 의심, 타인을 해칠 것 같은 공포 등)
</p>
</div>
<div style="background: #f0fdf4; border: 1px solid #bbf7d0; border-radius: 8px; padding: 18px;">
<h3 style="color: #15803d; margin-top: 0; font-size: 1.15rem; display: flex; align-items: center; gap: 6px;">
<span>🔄</span> 강박행동 (Compulsion)
</h3>
<p style="font-size: 0.95rem; color: #4a5568; line-height: 1.6; margin-bottom: 0;">
강박사고로 인해 폭발한 불안과 찝찝함을 일시적으로 가라앉히기 위해 반복하는 외적 행동이나 내적 행위입니다. 하지 않으면 큰 불행이 생길 것 같아 고통을 감수하며 되풀이합니다. (반복 손 씻기, 문 확인, 물건 정렬, 속으로 문장 암송 등)
</p>
</div>
</div>
<div style="background: #fff8f0; border-left: 4px solid #f39c12; padding: 14px 18px; border-radius: 4px; font-size: 0.95rem; color: #5d4037; line-height: 1.6;">
<strong>※ 눈에 보이는 행동이 없어도 강박증일 수 있습니다 (정신적 강박 / Pure-O)</strong><br>
모든 강박증 환자가 손을 씻거나 문을 확인하는 것은 아닙니다. 겉으로는 가만히 있는 것처럼 보이지만 머릿속에서 지나간 대화를 계속 되짚거나, 특정 단어를 반복하고, 끊임없이 스스로 '괜찮다'는 논리적 확신을 구하는 <strong>'정신적 강박(내적 강박)'</strong> 역시 심각한 강박장애의 한 형태입니다.
</div>

<p class="cond-card-title" style="font-size: 1.15rem; font-weight: bold; color: #1e3a8a; margin-top: 0;">1. 오염·청결 강박</p>

<li>손을 피부가 헐고 피가 날 때까지 씻고 또 씻음</li>

<li>타인이 만진 문손잡이나 대중교통 손잡이를 절대 맨손으로 만지지 못함</li>

<ul style="padding-left: 18px; margin: 8px 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">

<li>보낸 메시지나 이메일에 치명적인 실수가 있는지 수십 번 다시 열어봄</li>
<li>스스로에게 확신이 서지 않아 하루의 많은 시간을 확인 작업에 소모함</li>

<p class="cond-card-title" style="font-size: 1.15rem; font-weight: bold; color: #1e3a8a; margin-top: 0;">3. 건강·질병 관련 강박</p>
<ul style="padding-left: 18px; margin: 8px 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
<li>신체의 사소한 통증이나 감각 변화에 극도로 예민하게 반응함</li>
<li>암, 심장마비, 뇌졸중 등 치명적 불치병에 걸렸을까 봐 인터넷을 밤새 검색함</li>
<li>병원에서 각종 정밀검사를 받아 정상 판정을 받아도 결과를 불신함</li>
<li>가족이나 의료진에게 "나 괜찮은 거 맞지?"라며 끊임없이 안심을 구함</li>
</ul>
</div>

<div class="cond-card" style="border: 1px solid #e2e8f0; border-radius: 8px; padding: 18px; background: #fff;">
<p class="cond-card-title" style="font-size: 1.15rem; font-weight: bold; color: #1e3a8a; margin-top: 0;">4. 대칭·정리·완벽주의 강박</p>
<ul style="padding-left: 18px; margin: 8px 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
<li>물건의 배열, 책상 위 필기구의 각도가 완벽하게 일치해야 마음이 편안함</li>
<li>특정 숫자(행운의 숫자, 불길한 숫자)에 집착하여 특정 횟수만큼 행동함</li>
<li>무언가 '딱 들어맞아야 한다(Just right sensation)'는 느낌이 들 때까지 반복</li>
<li>순서가 조금이라도 흐트러지면 처음부터 모든 과정을 다시 시작해야 함</li>
</ul>
</div>

<div class="cond-card" style="border: 1px solid #e2e8f0; border-radius: 8px; padding: 18px; background: #fff;">
<p class="cond-card-title" style="font-size: 1.15rem; font-weight: bold; color: #1e3a8a; margin-top: 0;">5. 침투적 금기사고 강박</p>
<ul style="padding-left: 18px; margin: 8px 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
<li>"내가 칼을 들고 누군가를 찌르면 어쩌지?", "아이를 해치면 어쩌지?"라는 공포</li>
<li>종교적 신성모독이나 원치 않는 성적인 잔혹한 이미지가 머릿속에 침투</li>
<li>실제로 행동할 의도가 전혀 없는데도 그런 생각이 든다는 사실에 심한 자책감</li>
<li>자신이 괴물이나 사이코패스가 아닐까 두려워 칼이나 위험한 물건을 치워둠</li>

<li><strong>세로토닌·도파민 신경전달물질 불균형</strong>: 충동 억제와 마음의 안정을 담당하는 신경전달물질의 균형이 깨져 사소한 자극도 재난처럼 증폭됩니다.</li>
<li><strong>생각 억제의 역설(백곰 효과)</strong>: 억지로 "생각하지 말아야지" 하고 참으려 할수록 뇌는 그 사고에 더 강하게 집착하게 됩니다. 따라서 참는 것이 아니라 뇌의 민감도를 낮추는 치료가 핵심입니다.</li>

<div class="cond-section">
<h2 class="cond-h2">강박증 자주 묻는 질문 (FAQ BEST 10)</h2>
<p style="color: #666; margin-bottom: 16px;">환자분들과 보호자분들께서 가장 자주 주시는 질문들을 모아 알기 쉽게 답변해 드립니다.</p>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q1. 손을 자주 씻거나 정리정돈을 잘하면 강박증인가요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
단순히 손을 자주 씻거나 정리를 좋아하는 습관만으로 강박증이라 진단할 수는 없습니다. 중요한 차이는 <strong>'통제력'과 '고통의 유무'</strong>입니다. 오염에 대한 비합리적인 공포와 불안 때문에 어쩔 수 없이 손을 씻고, 그로 인해 일상생활에 지장이 발생하며 스스로 멈추기 힘들다면 강박증 여부를 평가받아야 합니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q2. 문이나 가스를 몇 번씩 확인하는데 치료를 받아야 하나요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
누구나 급할 때 한두 번 확인할 수 있습니다. 하지만 확인을 마쳤음에도 불구하고 확신이 서지 않아 문앞을 떠나지 못하거나, 집을 나섰다가 다시 돌아오기를 반복하고, 확인하지 않으면 극심한 불안으로 가슴이 뛰는 단계라면 뇌의 안전 신호 필터링 오류이므로 조기 치료가 필요합니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q3. 계속 질병을 검색하고 병원 결과를 의심하는 것도 강박증인가요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
네, 전형적인 '건강·질병 확인 강박'의 양상입니다. 건강에 대한 불안 때문에 끊임없이 질병을 검색하고, 검색 결과를 보고 잠시 안도했다가 이내 새로운 의심이 생겨 검색을 반복하는 패턴은 강박의 고리입니다. 건강염려증 및 범불안장애와의 감별을 통해 뇌의 불안 감각을 안정시켜야 합니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q4. 원하지 않는 이상하고 끔찍한 생각이 자꾸 떠오르는데 제가 위험한 사람인가요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
절대 아닙니다. 강박증에서 나타나는 침투적 사고(타인을 해치거나 성적·불경한 생각)는 <strong>환자 본인의 실제 인격이나 행동 의도와 정반대</strong>입니다. 오히려 지나치게 도덕적이고 양심적인 분들에게 이런 생각이 침투하여 심한 죄책감과 공포를 일으킵니다. 그 생각은 환자분의 본심이 아니라 뇌 신경회로의 오작동 신호일 뿐입니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q5. 겉으로 드러나는 행동 없이 머릿속으로만 생각하는 것도 강박증인가요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
네, 가능합니다. 이를 <strong>'정신적 강박(Mental Compulsion / Pure-O)'</strong>이라고 합니다. 눈에 보이는 행동 대신 머릿속으로 과거 기억을 확인하거나, 특정 기도문이나 숫자를 반복하고, 논리적인 답을 찾기 위해 계속 생각을 되짚는 행위 역시 불안을 줄이기 위한 강박행동의 한 형태입니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q6. 의지로 억지로 참으려고 할수록 왜 더 심해질까요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
뇌의 <strong>'백곰 효과(생각 억제의 역설)'</strong> 때문입니다. "흰곰을 생각하지 마라"고 명령하면 온통 흰곰만 떠오르듯, 생각을 억지로 누르려 할수록 뇌는 그 사고에 더 강하게 집착합니다. 강박증은 참는 의지의 문제가 아니라, 뇌 신경계의 과열을 식히고 자생력을 키우는 의학적 치료가 선행되어야 합니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q7. 강박증과 틱장애가 같이 나타날 수도 있나요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
네, 매우 흔하게 함께 나타납니다. 특히 소아·청소년 환자의 경우 눈 깜빡임, 헛기침 등의 틱 증상과 물건 정렬, 확인 강박이 동시에 동반되는 경우가 많습니다. NIMH 역시 강박증과 틱장애의 높은 동반율을 보고하고 있으며, 두 질환은 <strong>기저핵 조절 미숙</strong>이라는 동일한 기전을 공유하므로 통합 치료가 매우 효과적입니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q8. 강박증 완치가 가능한가요? 치료하면 정말 좋아질 수 있나요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
네, 충분히 회복될 수 있습니다. 뇌의 신경 필터링 오류를 정상화하고 충동에 대한 뇌의 민감도를 낮추면, 강박사고가 머릿속에 스치더라도 불안이나 공포 없이 자연스럽게 흘려보낼 수 있는 안정된 상태로 회복됩니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q9. 강박증 약(양약)을 꼭 먹어야 하나요? 한방 치료와 병행할 수 있나요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
모든 사람이 양약을 복용해야 하는 것은 아닙니다. 증상의 경중과 연령, 동반 증상에 따라 결정됩니다. 이미 SSRI 등 신경정신과 약물을 복용 중이신 경우에도 한방 치료를 안전하게 병행할 수 있으며, 한약과 두뇌 훈련을 통해 뇌 자생력이 강화되면 의료진과 상의하여 양약을 점진적으로 감량해 나갈 수 있습니다.
</p>
</details>

<details class="faq-item" style="border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 10px; padding: 14px; background: #fff;">
<summary style="font-weight: bold; color: #1e3a8a; cursor: pointer; font-size: 1.02rem;">Q10. 강박증인지 확실하지 않은데 전화상담부터 받아도 되나요?</summary>
<p style="margin: 10px 0 0 0; color: #475569; font-size: 0.95rem; line-height: 1.65;">
