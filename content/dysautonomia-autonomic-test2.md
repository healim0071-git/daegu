<!-- 1. 섹션 -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
1. 자율신경계 이상으로 발생하는 3대 기립 질환
</h2>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; margin: 18px 0;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">① 기립성 저혈압 (Orthostatic Hypotension)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
기립 후 3분 이내 수축기 혈압 20mmHg 또는 이완기 혈압 10mmHg 이상 감소하며 아찔한 어지럼증과 시야 흐림이 발생합니다.
</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">② 기립성 빈맥 증후군 (POTS)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
혈압 저하 없이 일어선 상태에서 맥박수가 분당 30회 이상 급증하며 가슴 두근거림, 피로감, 어지럼이 지속되는 청년기 호발 질환입니다.
</p>
</div>
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 20px;">
<strong style="color: #146369; font-size: 1.05rem;">③ 미주신경성 실신 (Vasovagal Syncope)</strong>
<p style="margin: 6px 0 0; font-size: 0.94rem; color: #475569; line-height: 1.65;">
극도의 긴장, 통증, 피로 상황에서 미주신경(부교감)이 과도하게 반응하여 순간적으로 심박과 혈압이 급강하하며 의식을 잃는 증상입니다.
</p>
</div>
</div>


<!-- 2. 섹션 -->

2. 기립 혈류 반사를 강화하는 한방 보증익기 치료
</h2>

<p>
해아림한의원에서는 하체의 혈액을 뇌로 끌어올리는 기운을 보강하는 <strong>보중익기탕(補中益氣湯) 및 승양기혈(升陽氣血) 처방</strong>과 하체 정맥 순환을 돕는 침구 치료를 통해 기립성 뇌혈류 장애를 근본적으로 치료합니다.
</p>


<!-- 3. 자주 묻는 질문 FAQ -->
<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
자주 묻는 핵심 질문 (FAQ)
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">

<details class="faq-item" open style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q1. 이석증 치료 후에도 어지러운데 자율신경 이상일까요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 네. 이석 정복술 후 남아있는 잔여 어지럼증(지속성 체위 어지럼)은 자율신경계 조절력과 뇌간 혈류 장애가 원인인 경우가 매우 많습니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q2. 기립성 어지럼증 검사는 어떻게 진행되나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 누운 상태에서 혈압과 맥박을 측정한 뒤, 일어선 직후 1분, 3분, 5분 간격으로 혈류 변동 추이를 정밀 기록합니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q3. 실신할 것 같은 전조 증상이 올 때는 어떻게 해야 하나요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 즉시 바닥에 쪼그려 앉거나 누워 다리를 높이고, 다리를 꼬아 허벅지와 종아리 근육에 힘을 주는 카운터 프레셔 동작을 취하세요.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q4. 빈혈 수치는 정상인데 왜 어지러울까요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 빈혈은 혈액 속 헤모글로빈이 부족한 것이고, 자율신경성 어지럼은 혈액량은 정상이지만 뇌로 보내는 펌프 스위치(신경)가 느린 것으로 서로 다른 질환입니다.
</div>
</details>

<details class="faq-item" style="background: #F8FAFB; border: 1px solid #D6E4EE; border-radius: 10px; padding: 14px 18px;">
<summary style="font-weight: 800; color: #0C4349; cursor: pointer;">
Q5. 검사 예약 시 금식이 필요한가요?
</summary>
<div style="padding-top: 10px; color: #475569; font-size: 0.95rem; line-height: 1.7;">
A. 식사 직후에는 소화기로 혈액이 쏠려 측정에 오차가 생길 수 있으므로 식사 후 최소 2시간 뒤에 검사를 받으시는 것이 이상적입니다.
</div>
</details>
