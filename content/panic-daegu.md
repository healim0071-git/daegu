</h2>
<p style="margin: 0 0 12px; color: #334155;">
공황장애가 삶을 지치게 만드는 진짜 이유는 발작이 몰아치는 20~30분간의 고통 때문만이 아닙니다. 발작이 지나간 뒤에도 <strong>"회의 중에, 운전 중에, 지하철 안에서 또 숨이 막히면 어쩌지?"</strong>라는 두려움에 온 신경이 곤두서고, 결국 익숙했던 출퇴근길과 외출마저 포기하며 삶의 반경이 좁아지기 때문입니다.<br>
해아림한의원 대구본점은 <strong>16년 이상 공황장애·불안·자율신경 질환을 중점 진료해온 김대억 대표원장(한방신경정신과 박사 / 『걱정마 공황장애』 저자)</strong>이 가짜 경보를 울리는 뇌 편도체와 자율신경계의 균형을 근본부터 조율합니다.
</p>

💡 위치 및 진료: 대구 지하철 2호선 범어역 1·4번 출구 바로 앞 두산위브 상가 3층 (무료 지하주차 지원 / 평일 월·화·수·금 20시 야간진료, 토요일 16시까지 연속 진료)

① 신체 감각의 파국화 5단계 루프
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
피로·수면부족·카페인 등으로 인한 가벼운 맥박 상승을 뇌가 <strong>"큰일 났다, 심장이 멈추거나 죽을 것 같다"</strong>고 파국적으로 오해석하면, 편도체가 교감신경을 폭주시켜 실제 호흡곤란, 어지럼증, 식은땀, 손발 저림 등 격렬한 공황발작을 촉발합니다.

② 예기불안과 회피 행동(광장공포증)의 확산
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">

<h2 style="font-size: 1.35rem; font-weight: 800; color: #0C4349; border-left: 4px solid #146369; padding-left: 12px; margin: 36px 0 18px;">
4. 공황장애 극복을 위해 꼭 알아두어야 할 핵심 Q&amp;A
</h2>

<div style="display: flex; flex-direction: column; gap: 14px; margin-bottom: 30px;">
<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 공황발작이 오면 정말 숨이 막혀 질식하거나 심장이 멎을 수도 있나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 결코 그렇지 않습니다. 발작 순간에는 당장 죽을 것 같은 극도의 공포가 느껴지지만, 이는 교감신경계가 일시적으로 과도하게 흥분해 나타나는 생리적 반응일 뿐 실제 심장마비나 질식을 일으키지 않습니다. 대개 10~20분 내 정점을 지나 30분 안에 저절로 가라앉으며, "이 반응은 위험하지 않은 가짜 경보다"라는 사실을 뇌에 각인시키는 것이 회복의 첫걸음입니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 공황발작 때 왜 머리가 핑 돌고 손발이 저리며 쓰러질 것 같을까요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 불안으로 인해 숨을 빠르고 얕게 몰아쉬는 '과호흡'이 나타나면 혈액 속 이산화탄소 농도가 급격히 낮아지면서 뇌혈관이 일시적으로 수축하기 때문입니다. 이로 인해 어지럼증, 시야 흐림, 손발 끝 저림이 발생하지만 뇌졸중 같은 뇌 손상이 아니므로 호흡 속도를 천천히 늦추면 빠르게 진정됩니다.
</p>
</div>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q3. 커피 한 잔이나 가벼운 음주도 공황 증상에 영향을 주나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 네, 직접적인 악화 요인입니다. 카페인은 중추신경과 심박수를 자극해 뇌가 이를 공황 전조 증상으로 착각하게 만들며, 알코올은 분해되는 숙취 과정에서 자율신경계를 교란해 다음 날 심한 반동성 불안과 발작을 유발하므로 치료 기간에는 금하시는 것이 좋습니다.
</p>
