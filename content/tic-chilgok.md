<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q1. 아이가 눈을 심하게 깜빡이는데, 안과 질환(결막염)이나 알레르기 비염과 어떻게 구별하나요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 안과나 이비인후과 치료를 2~3주 이상 받아도 증상이 지속되거나, 안약 처방 후 잠시 가라앉았다가 다시 눈을 깜빡인다면 틱을 의심해야 합니다. 특히 TV나 스마트폰을 볼 때, 피곤하거나 긴장할 때 깜빡임이 심해지고, 눈 깜빡임 외에 코 찡긋이나 고개 움직임 등 다른 동작으로 형태가 변한다면 뇌 신경계 조절 기능 이상인 틱장애일 가능성이 매우 높습니다.
</p>

<div style="background: #FFFFFF; border: 1px solid #E2E8F0; border-radius: 12px; padding: 18px 20px;">
<h3 style="font-size: 1.05rem; font-weight: 800; color: #0C4349; margin: 0 0 6px;">
Q2. 칠곡 왜관이나 석적에서 대구 범어역까지 아이와 함께 통원하기에 힘들지 않을까요?
</h3>
<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 전혀 부담스럽지 않습니다. 왜관역에서 기차를 타시면 대구역이나 동대구역까지 20여 분, 이후 지하철로 범어역 1·4번 출구 앞 상가 건물로 바로 연결됩니다. 자가용 이용 시에도 경부고속도로 왜관IC나 대구외곽순환도로를 이용하면 30~35분이면 도착하며, 상가 지하 2시간 무료 주차를 지원합니다. 치료 초기 3~4주는 주 1회, 이후에는 격주 1회 내원으로 충분히 호전 경과를 이끌어낼 수 있습니다.
</p>

Q3. 한약 복용 시 어린아이가 쓴맛 때문에 거부하지 않을지, 성장 발육에 문제는 없는지 걱정됩니다.

<p style="margin: 0; font-size: 0.95rem; color: #475569;">
A. 해아림한의원의 소아 틱 한약은 쓴맛과 거부감을 최소화하여 어린아이들도 순하게 복용할 수 있도록 정성껏 조제됩니다. 또한 식약처(KFDA) 엄격 인증 규격품 한약재만을 사용하며, 뇌 신경 안정뿐 아니라 아이의 체질적 면역력과 식욕, 성장 발육을 함께 돕는 보음(補陰)·건비(健脾) 약재가 조화롭게 가미되어 안심하고 복용시키셔도 좋습니다.
